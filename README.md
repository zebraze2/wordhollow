# Wordhollow

A cozy pixel-art spelling adventure for grades 1–2. Walk around a village, help the
neighbors by spelling words from dictation, and watch their homes and gardens bloom.

Play: https://zebraze2.github.io/wordhollow/

- Eight lands, each teaching one spelling pattern (short vowels → digraphs → blends →
  silent e → vowel teams → bossy r → word parts). Land 1 is open; more are coming.
- Research-based practice: dictation (hear, then build the word — never choose among
  misspellings), sound boxes that fade over time, error correction with study-cover-recall,
  heart words for irregular spellings, and spaced review of missed and learned words.
- No build step: static HTML/JS. Voice clips are pre-recorded with Kokoro (see `tools/README.md`).

Run locally: `python3 tools/serve.py` then open http://localhost:5176
